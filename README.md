# Hermes Robot 角色定义

## 功能介绍

### 核心定位
**Hermes 多智能体系统的 7 个角色定义**：1 个 Main（系统管理员）+ 6 个 Robot（专业分析），各司其职，协同工作。

### 角色架构
```
┌─────────────────────────────────────────────────────────────┐
│                    Hermes 集群架构                          │
├─────────────────────────────────────────────────────────────┤
│  Main (系统管理员) ──────────────────────────────────────┐  │
│      管理所有 Robot 实例、部署、权限控制、系统审计        │  │
├─────────────────────────────────────────────────────────────┤
│  Robot-1 系统维护+策略 ─────── 最高权限，信号汇总决策    │  │
│  Robot-2 市场热点分析 ──────── A股/港股/美股热点挖掘     │  │
│  Robot-3 持仓管理 ──────────── 持仓监控、止盈止损预警    │  │
│  Robot-4 超短线交易 ────────── 盘中标的筛选与追踪        │  │
│  Robot-5 四维分析 ──────────── 技术/基本面/消息/资金     │  │
│  Robot-6 市场分析专家 ──────── 趋势分析、大盘研判        │  │
└─────────────────────────────────────────────────────────────┘
```

### 输出流程
```
R2(热点) → R5(四维) → R1(策略汇总) → R6(趋势) → R4(短线) → R3(持仓预警) → 用户决策
```

## Main - 系统管理员

| 属性 | 值 |
|------|-----|
| **目录** | `~/.hermes/` |
| **Feishu App** | robot-管家main |
| **角色** | 🖥️ 系统管理员 |

### 职责
- 部署管理：启动/停止/重启 Gateway，监控各 Robot 运行状态
- 权限控制：管理各 Robot 的访问权限，配置环境变量和 API Key
- 系统审计：检查配置一致性，记录操作日志
- Skill 管理：创建/分配/收回任意 Robot 的 Skill

### 权限边界
- ✅ 管理所有 Robot 配置
- ✅ 启动/停止任何 Robot
- ✅ 修改系统级配置
- ❌ 不参与市场分析、股票推荐、交易建议

### 预警规则
| 类型 | 条件 | 动作 |
|------|------|------|
| 止盈预警 | 盈利 ≥ 目标涨幅 | 建议分批止盈 |
| 止损预警 | 亏损 ≥ 止损线 | 建议止损 |
| 异动预警 | 单日涨跌幅 ≥ 5% | 提示关注 |
| 仓位预警 | 单只仓位 ≥ 总资金 30% | 建议减仓 |

## 安装使用

### 下载
```bash
# 从 GitHub 下载
git clone https://github.com/jinfenghua1990/hermes-robots.git

# 或从 Gitee 下载（国内更快）
git clone https://gitee.com/ginohei/hermes-robots.git
```

### 部署
将对应的 SOUL.md 文件复制到各 Robot 实例目录：
```bash
# Main
cp main-SOUL.md ~/.hermes/SOUL.md

# Robot-1~6
cp robot-1-SOUL.md ~/.hermes-robot-1/SOUL.md
cp robot-2-SOUL.md ~/.hermes-robot-2/SOUL.md
# ... 以此类推
```

### 发版
```bash
./release.sh v1.2.0 "更新说明"
```
